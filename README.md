 # NetFlix Movies and TV shows Data Analysis using SQL
 
 This project explores the Netflix Movies and TV Shows dataset using SQL to answer business related questions and uncover valuable insights about Netflix's content library

# Objectives
* Analyze the distribution of Movies and TV Shows.
* Identify the most common content ratings.
* Explore content released over the years.
* Find the countries producing the most Netflix content.
* Analyze popular genres and categories.
* Examine movie durations and TV show seasons.

# Key Insights
* Movies make up a larger portion of the Netflix catalog than TV Shows.
* The United States contributes the highest number of titles.
* Drama and International Movies are among the most common genres.
* Netflix has significantly expanded its content library over recent years.
* TV-MA is one of the most frequently assigned content ratings
